# 锻体 Mod 2.8.37

本次更新包含：

- 每累计获得 10 级附魔，选择背包 +1 格、无视防御 +3% 或 HP 偷取 +1%；关闭窗口保留领取资格。
- 冰川重担加入冻伤伤害与冻结门槛降低，重新分配 400 点预算；锻体新增冰川冻伤配方。
- 增加繁体中文支持，跟随游戏语言设置。
- 背包入口改为紧凑文字标签，支持拖动；重担数值显示绿色，属性图标移至行首。
- 统一经济及行星普通属性点价，补入攻击范围、耗 MP 增伤等词条。
- 增加可选 SP 与 SilentInventory 联动，优化队伍属性刷新与收益页刷新。

下载 ZIP 后退出游戏，将包内 BodyForge 文件夹覆盖到游戏 AddOns 目录。心之重担装备功能联机时，房主与客机均需安装相同版本。
