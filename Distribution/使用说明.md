# 锻体 Mod 使用说明

适用版本：**2.8.22**。

锻体可以消耗一件神器或石板，从三份配方中选择一份获得属性；非普通材料还会为你选择的另一件神器增加附魔层数。

## 安装与开启

将完整的 `BodyForge` 文件夹放入游戏的 `AddOns` 目录，保留文件夹内自带的 DLL、`metadata.json` 和 `config.json`，然后启动游戏。更新文件前请退出游戏。

本 Mod 使用游戏原生 AddOn 加载方式，默认开启，**不依赖 SPMod、SilentInventory 或 BepInEx**。

## 如何锻体

### 心之重担：随指向切换装备属性

此功能联机时需要**房主与客机均安装相同版本的锻体 Mod**。

将原版“心之重担”放在想适配的神器下方一格，即可根据上方神器的羁绊切换它自身的装备属性。支持行星、坚固、元素、风之歌、守护、精密、影子、学院、湖泊、太阳剑、冰霜武具、乌云、余烬、冰川、魔法科技、诅咒、同伴、谈判、神秘、炼金。目标有多个适配羁绊时，按上述顺序取第一组，不叠加多组。

选中背包内的心之重担时，可适配的神器会显示原生高亮，当前生效目标另有等级提升框提示；原版指北针能转接到有效目标时也会高亮。高亮表示该神器可作为目标，实际适配仍要求放在重担上方。移开选择后由原生 UI 清除提示。

上方是原版金针或蓝针时，会沿其指向继续查找。上方空置、不是神器、没有适配羁绊或形成循环时，不提供适配属性及连击。可以在心之重担的原生道具说明中查看当前适配与数值。简介随当前适配切换为预定的 17 句台词，只展示句子，不加人物署名；无有效目标或在日志、许愿台预览未持有的重担时，显示“如果一直锻造的话...”。

心之重担也提供当前适配羁绊的实际连击数：附魔 0～2 级 +1、3～7 级 +2、8～12 级 +3、13～14 级 +4、15 级及以上 +5。切换指向或移除重担后由原生背包重新结算。装备属性、额外次数解锁、连击档位和锻体预算统一只按永久附魔等级计算，最多按 15 级结算；石板等临时加级不提高这些效果。

所有适配共用“锻体属性预算”词条：永久附魔等级每级 +2%，最多 +30%；无适配目标时也保留这项加成。多件重担取最高的一件，不叠加。首次生成配方或消耗重掷次数时计算，已经生成的候选不自动改写；取消重开也不会免费刷新。加成提高分配给属性的预算，不是每一条数值精确乘算；整数取整和属性上限可能使个别词条不变。附魔层数、重掷次数、扩容规则与特殊次数奖励不因此增加。

### 吞噬与配方

1. 进入冒险，打开角色背包，点击背包旁的 **锻体** 按钮。
2. 点击 **开始锻体**，在主背包或下方副背包选择一件神器或石板作为材料。堆叠物品每次只消耗一件。
3. 普通白色材料直接进入配方选择；其他稀有度需要再选择**主背包中的另一件已有神器**作为附魔目标，石板不能作为目标。
4. 查看三份配方，选择其中一份。每份包含一至两项奖励，选中后会获得该配方的全部奖励。
5. 如果还有重掷次数，可以点击 **重掷全部**，重新生成三份配方。
6. 在确认界面核对材料、目标、附魔层数和属性，再确认锻体。
7. 完成后可以 **查看收益**，或点击 **继续锻体** 开始下一次。

材料被消耗后，它原有的属性和羁绊也会失去。请不要把仍然需要的关键装备当成材料。

开始前请关闭商店、宝箱和奖励等特殊背包界面，并放下鼠标正拿着的物品；材料可从主背包或下方副背包选择；副背包中的道具不能作为附魔目标。

### 取消与关闭

- 选择材料或目标时，可用鼠标右键取消。
- 弹窗可以通过右上角 **×** 或 Esc 关闭；最终确认前不会消耗材料。
- **确认后关闭背包不会取消正在进行的结算**。需要停止时使用停止按钮，它只会阻止后续请求，已经发出的请求仍可能生效。
- 联机时打开锻体界面不会暂停游戏。

## 稀有度、附魔与重掷

| 材料稀有度 | 附魔层数 | 每件材料可重掷次数 |
| --- | ---: | ---: |
| 普通（白色） | 0 | 0 |
| 罕见（蓝色） | +1 | 1 |
| 稀有（黄色） | +2 | 2 |
| 传奇（紫色） | +3 | 3 |
| 永恒 | +5 | 5 |

**重掷不消耗骰子**，每次会重掷全部三份配方。重掷可能再次出现之前的配方。

同一件材料取消后重开、换附魔目标，不会恢复重掷次数或免费刷新候选。堆叠材料确认消耗一件后，下一件才拥有新的配方和重掷次数。

高稀有度材料拥有更高的属性预算，但不是简单将属性乘以附魔次数，也不保证每份配方都是两条属性。

通用配方不提供火焰、冰霜、雷电单系伤害，保留最高元素伤害。对应元素仍可通过已激活羁绊的构筑倾向配方获得。

## 配方如何偏向当前构筑

通常生成 **两份偏向当前构筑的配方，加一份通用配方**，三份的位置会打乱，通用配方不固定在某一栏。可用构筑或不重复配方不足时，会用通用配方补足。

构筑判断参考角色当前已激活的全部羁绊连击，不仅参考被吃掉的材料。先抽取羁绊体系，再抽取该体系的配方；同一体系拥有更多配方，不会因此获得额外的抽取优势。连击档位越高，体系权重越高，但不会直接增加每份配方的属性预算。

例如，风之歌偏向攻速与移速，守护偏向防御、最大生命与伤害放大，冰霜武具偏向冰伤、武具伤害和充能，太阳剑偏向火伤、剑伤、掉落速度等。

每件材料首次生成配方时会记录当时的连击情况。之后更换装备、取消重开或重掷，不会更新这件材料的连击快照。

学院新增魔法书暴击／爆伤、魔法伤害与 MP 消耗降低；同伴新增攻速／暴击；湖泊新增 MP 再生倍率／最大 MP 放大；太阳剑新增无视防御；元素加入通用暴击率与移速。这些搭配仍使用原有材料预算。魔法书减耗和太阳剑无视防御单卡最多 10 个百分点，当前总加成达到 50% 后不再提供。

### 特殊奖励与限制

- **附魔里程碑**：每累计确认获得 10 级附魔，领取一次三选一：背包 +1 格／无视防御 +3%／HP 偷取 +1%。背包奖励本局最多 10 格，总容量不超过 120 格。关闭窗口保留资格，可从锻体入口领取。白色材料不推进附魔进度；计数按附魔等级总数，不按锻体次数。
- **HP 吸取**：仅传奇、永恒材料有机会获得；每组三选一出现概率分别为 6% 和 9%。数值采用游戏原生单位，不能把“+1”直接理解为每次命中回复 1 点或吸取 1%。
- **次数、层数机制卡**：传奇／永恒每组三选一分别有 6%／10% 机会尝试提供，仍需激活对应体系并满足限额。包括冰武额外触发、燃烧叠层、电击叠层、额外闪避次数、太阳剑额外容量。机制固定 +1，先扣预算，剩余点数可搭配一条同体系普通属性。冰武额外触发／额外闪避当前加成达 1 后不再提供，另外三项达 2 后不再提供；会计入装备现有加成。
- **谈判力、金币掉落及常规属性**：没有锻体整局累计硬上限，但每次配方仍受预算约束。

当前不再抽到 **MP 吸取、HP 自动回复、药水效果、太阳剑专用暴伤**。HP 吸取与 MP 回复仍保留。已获得的旧奖励不会因移出池子而被删除。

## 查看锻体收益

在锻体首页点击 **查看锻体收益**，或在锻体结果页点击 **查看收益**。

- 顶部固定显示已消耗材料、已确认附魔，以及扩容额度，例如“消耗 28 件 · 附魔 +65 · 扩容 6/10”。
- 点击 **展开详情** 查看完成、中止次数和统计说明。
- 中间按通用伤害、生存恢复、元素伤害、专属效果、其他收益分组；专属效果再按冰武、太阳剑、乌云等体系排列。
- 使用鼠标滚轮滚动，也可以拖动右侧滚动条，取消了原来的分页。
- 宽窗口显示两列，窄窗口自动切换为一列；长名称会换行。
- 同组属性按首次获得的顺序排列，增加数值时不会重新打乱。
- 最近一次锻体获得的属性会显示“本次 +数值”，打开收益页或更新时短暂高亮，累计值同时保留。

收益页**只统计本次连接、当前冒险中确认到账的锻体奖励**，不会把装备原有属性算进去。中途停止时，已确认的部分仍保留。

新冒险会清空统计；重启或重新连接后，不会从历史日志恢复这份累计显示。**统计清空不等于实际属性被撤销**，实际奖励的保存由游戏负责。

## 调整界面

### 移动背包旁的按钮

鼠标左键按住 **锻体** 按钮即可拖动；普通点击仍然打开界面。拖动不会改变按钮图标。

按钮位置在同一次游戏运行期间保留，重启游戏后恢复自动位置。

### 调整窗口大小

拖动弹窗**右下角的金色手柄**：向右下拖动放大，反向拖动缩小。

- 配方、确认等普通弹窗会连同文字和按钮等比缩放。
- 收益窗口调整的是可用显示空间，文字保持正常字号，按宽度切换单列／双列。
- 窗口使用当前游戏选择的字体，并受屏幕边界限制。
- 尺寸在同一次游戏运行期间保留，重启后恢复默认。

目前只有背包旁的入口，**没有独立的 F8／Ins 快捷键面板**。

## 配置开关

退出游戏后，用文本编辑器打开同目录的 `config.json`：

```json
{
  "Enabled": true,
  "EnableSpecializedRewards": true
}
```

| 配置项 | 作用 |
| --- | --- |
| `Enabled` | 总开关。`true` 开启，`false` 关闭锻体 Mod。 |
| `EnableSpecializedRewards` | 是否允许专属机制属性进入初次抽取和重掷。默认开启。 |

关闭 `EnableSpecializedRewards` 后：

- 太阳剑、余烬仅保留火焰伤害倾向。
- 冰霜武具、冰川仅保留冰霜伤害倾向。
- 乌云、魔法科技仅保留雷电伤害倾向。
- 诅咒、同伴、谈判没有对应元素替代，不再提供专属倾向。
- 风之歌、守护等普通面板属性倾向不受影响。
- 已经获得的专属奖励不会被移除或转换，仍可在收益中查看。

修改后重新启动游戏生效。请使用小写 `true`／`false`，保留引号、逗号和大括号；无需添加其他配置项。

## 常见问题

### 专属属性为什么不显示在人物面板？

人物面板不会列出所有专属机制属性。冰武充能、太阳剑掉落速度等通常作用于对应机制，可以在锻体收益中查看已确认的加成。需要拥有对应玩法才能发挥效果；如果吞掉了唯一提供该机制的装备，相关加成可能暂时无从触发。

### 提示未确认、同步超时或中止怎么办？

先检查材料、目标附魔和实际属性。消耗材料、附魔、发放属性是分步执行的，可能只完成其中一部分，不能保证全部同时成功，也不会自动退款或回滚。

每一步最多等待约 8 秒，不会自动反复重发。发生异常锁定后，等待约 8 秒并核对实际结果，再通过 **解除锁定** 恢复操作；这不会补发旧请求。

### 可以在联机客机使用吗？

锻体通过游戏原生请求执行操作，包含客机的同步与核对流程，不依赖房主安装其他辅助 Mod。不过网络延迟、游戏版本和其他 Mod 仍可能影响结果；不能把本地确认当作所有联机场景都已验证。出现异常时按上一项处理。

### 哪里可以查看操作记录？

同目录的 `forge-history.jsonl` 保存历史操作记录，可用于排查问题。它不是存档恢复文件，不会自动恢复收益页统计。

反馈问题时，建议提供 Mod 版本、单机／房主／客机身份、材料稀有度、所选配方、报错截图，以及相关操作记录。
